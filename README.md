# TERJ Cross-Spectral

Independent cross-domain spectral experiment.

This repository is intentionally separate from the completed
`riemann-terj` project.

Research question:

After removing symmetry-class, finite-size and scale effects,
do spectra associated with Riemann zeros and trained neural
networks retain a statistically detectable common residual
relational structure beyond their respective random-matrix
null models?

The project does not assume that Riemann zeros and neural
networks are physically identical systems.

Riemann data and previous riemann-terj results are treated as
external research inputs.
