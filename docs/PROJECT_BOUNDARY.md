# Project boundary

`terj-cross-spectral` is an independent research project.

The repository `riemann-terj` is treated as a completed,
separate project and must not be modified as part of this work.

Permitted use of riemann-terj:

- citation,
- reading published results,
- importing explicitly selected numerical outputs as external data,
- methodological comparison.

Not permitted:

- writing new cross-spectral code into riemann-terj,
- storing Neural production data in riemann-terj,
- modifying historical riemann-terj results to fit the new experiment,
- treating the two repositories as one Git history.

Primary external Riemann data may additionally come directly
from published Odlyzko zero tables and reproducible Arb/python-flint
computations.

The cross-domain hypothesis, analysis code, manifests, controls,
Neural data definitions and final results belong to this repository.
